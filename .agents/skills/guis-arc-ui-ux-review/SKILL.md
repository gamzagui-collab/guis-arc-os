# 목적
흑백 공통 구조 안에서 실제 현장 업무를 더 명확하고 안전하게 만든다.

## 사용 조건
- 화면 정보 구조, 주요 행동, 반응형, 접근성 또는 액션 피드백 검토에 사용한다.

## 사용하지 않는 경우
- 서버 오류 원인 조사나 단순 미적 취향 평가에는 사용하지 않는다.

## 먼저 읽을 문서
Required file: `AGENTS.md`
Required file: `DEVELOPMENT_RULES.md`
Required file: `VERSION.md`
Required file: `docs/04_UI_SYSTEM.md`

## 예상 문제·부작용·충돌
정보 과밀, 작은 조작 영역, 모호한 상태, 중복 클릭, 모바일 스크롤 충돌을 확인한다.

## 입력
사용자 역할·업무, 화면 코드 또는 배포 화면, Viewport와 기대 행동.

## 절차
기준본 확인 → 업무 우선순위 → PC·모바일·키보드·피드백 검토 → 문제와 실제 효과 구분 → 최소 개선 권고.

## 변경 허용 범위
기본은 검토이며 명시 요청 시 관련 화면·스타일·접근성 테스트만 최소 수정한다.

## 금지사항
주요 메뉴 삭제, 불필요한 영어, 기능 추가를 개선으로 단정, Production 변경을 금지한다.

## 테스트 및 검증
처리 중·성공·실패, 중복 차단, 360·390·412px, 키보드와 aria 상태를 확인한다.

## 완료 조건
현장 업무 효과와 접근성 문제, 최소 개선안이 구분된다.

## 결과 보고 형식
사용자 목표, 문제, 영향, 권고, Viewport·접근성, 미검증 순서로 보고한다.

## NOT_EXECUTED 기준
실제 렌더·브라우저·기기 검증을 하지 않았으면 정적 검토와 분리한다.
