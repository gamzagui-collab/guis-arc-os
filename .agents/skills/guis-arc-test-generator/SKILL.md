# 목적
실제 계약과 실패 위험을 검증하는 결정적 테스트를 만든다.

## 사용 조건
- 요구가 확정되고 관련 구현 또는 계약에 테스트가 필요할 때 사용한다.

## 사용하지 않는 경우
- 요구가 불명확하거나 Root Cause가 확인되지 않은 장애에는 먼저 조사 Skill을 사용한다.

## 먼저 읽을 문서
Required file: `AGENTS.md`
Required file: `DEVELOPMENT_RULES.md`
Required file: `VERSION.md`
Required file: `AIOS/PROJECT_STATE.md`

## 예상 문제·부작용·충돌
문자열 존재만 검사하는 거짓 양성, 구현 복제, 시간·순서 의존과 권한 누락을 점검한다.

## 입력
확정 계약, 변경 코드, 기존 테스트 관례, 실패·경계 사례.

## 절차
기준본 확인 → 검증할 계약 추출 → 정상·실패·권한·동시성 사례 설계 → 최소 테스트 추가 → 실행 → 결과 보고.

## 변경 허용 범위
관련 테스트와 필요한 fixture만 수정하며 운영 Mock 데이터는 추가하지 않는다.

## 금지사항
기능 축소, 구현과 다른 기대값, 불안정한 외부 의존, Production 데이터 사용을 금지한다.

## 테스트 및 검증
추가 테스트를 실행하고 관련 회귀와 전체 테스트 필요성을 판정한다.

## 완료 조건
계약별 성공·실패 경로가 결정적으로 검증된다.

## 결과 보고 형식
검증 계약, 추가 사례, 수정 파일, 실행 결과, 남은 공백 순서로 보고한다.

## NOT_EXECUTED 기준
환경·계정·배포가 필요한 테스트를 실행하지 못하면 정적 테스트와 별도로 표시한다.
