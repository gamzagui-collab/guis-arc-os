# 최소 범위 수정 절차

사용자가 “제목을 바꿔줘”처럼 작은 요청을 하면 다음과 같이 처리한다.

1. 해당 문구가 있는 파일을 검색한다.
2. 관련 화면 파일과 직접 연결된 테스트만 읽는다.
3. 변경 범위를 짧게 선언하고 바로 수정한다.
4. 관련 테스트를 실행한다.
5. 공식 릴리스라면 버전을 증가시키고 Integrated ZIP을 만든다.
6. 배포가 필요한 경우 사용자가 실행할 명령은 가능한 한 하나만 제공한다.

다음 행위는 하지 않는다.

- 저장소 전체 재분석
- 관련 없는 문서 전체 재독해
- 요청하지 않은 구조 개편
- 관련 없는 전 테스트 반복 실행
- 사용자에게 수동 병합이나 소스 선택 요구
