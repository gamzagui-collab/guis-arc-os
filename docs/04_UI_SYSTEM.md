# UI System

Platform v0.11.5의 차분한 녹색 시각 언어를 토큰화했다. Top Header, Sidebar, Page Header, Site Selector, User Menu의 위치를 고정한다. 카드·버튼·상태·간격은 공통 package를 사용한다.

Desktop은 244px Sidebar와 64px Header, mobile은 Header·Context·Content·Bottom Navigation 구조다. 최소 touch target은 44px이다. module accent는 icon과 작은 indicator에만 사용하고 전체 Shell 구조는 동일하게 유지한다.
